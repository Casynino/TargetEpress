# Chinese wording: second opinions on live translations

A reviewed translation pass produced a different Chinese value for the keys
below than the one already shipping. Nothing here is broken — these are
judgement calls, and the shipped value was chosen deliberately in an earlier
pass, so none of them were applied automatically.

Most differences are about whether the phrase follows a number. `missing`
reads better as 件缺失 in "3 件缺失" and worse on its own; the shipped 缺失 is
the reverse. Whoever decides needs to see the screen, not the key.
